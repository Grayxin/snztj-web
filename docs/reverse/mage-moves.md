# 最终巫师 Boss：原程序静态证据与移植边界

分析对象：本目录 `Mystic.exe`，SHA-256 `9813a73c418d76499ca1eff6d676884e7d5f127cee821dd4a95e03fffb75fa4f`。仅使用 Python pefile 读取 PE、Capstone 汇编及静态控制流追踪，没有安装或运行 REA、Ghidra。下文招式名称为行为描述，并非原版技能名。

## 坐标、状态和动画

构造函数 `0x4094ce`，更新函数 `0x40a102`。原生位置 +0x1c/+0x20 是16.16定点；+0x1d4=40px、+0x1d8=94px；宿主网页以 x 中心、y 脚底存储，模块适配为原生左上角 `(e.x−40,e.y−96)`。原生瞄准使用 `+40,+94`，不是图片裁切后的矩形中心。角度65536一周，cos=`0x413593`、sin=`0x4134b0`；`0x413668(x,y)` 返回反向向量角度，因此原程序传“Boss−玩家”后，投射物实际朝玩家。

+0xfc 主动作、+0x100 倒计时、+0x110 招式序号、+0xec 下一招冷却、+0x11c HP阶段、+0x218 HP、+0x220 最大HP、+0x1b0 难度。难度=构造参数+global[0x51b368]×64；最终关配置基础参数32。动画表在 `0x492020`，每组128字节，资源0x36。站立0/1/2各8tick；移动3/4/5各8tick；状态1使用21..29各8tick、30为16tick；状态2使用31/32/33/34/35/36/34/35/36各8tick；3、6、7、8、10、12使用15/16/17/18/19/17/18/19/17/18/19各8tick；9、11、13循环17/18/19。状态动画映射分支 `0x40fc58..0x40fdd2`。

### 状态1：角度展开弹

84tick倒计时，50时记录玩家方向。难度≤64：49/35/22发射，速度5px/tick，角偏移−2560/0/+2560；65..128：49/42/35/29/22，速度6，偏移−3072/−1536/0/+1536/+3072；129..256：49/45/40/35/30/25/21，速度8，偏移−3072/−2048/−1024/0/+1024/+2048/+3072。偏移单位65536一周。发射点相对原生 `(x+40,y+94/3)` 分别为三发 `(32,0),(0,24),(−24,8)`；五发 `(32,0),(16,16),(0,24),(−16,16),(−24,8)`；七发额外重复两侧16,16点。构造 `0x422d7d`，更新 `0x423191`。证据 `0x40c46a..0x40cdc5`。

### 状态2与8：锁定落击与密集落击

状态2总120tick。难度≤64在76/46/16锁定玩家中心x，在61/31/1发射；65..128锁91/66/41/16，发76/51/26/1；129..256锁96/76/56/36/16，发86/66/46/26/6。构造423a4a实际按401f1e查地面，y=地面−480；传入−32不是最终y。vx=`(rand511<<9)−0x20000`，即约−2..2px/tick；每tick×95%，8tick后销毁（423fa6）。不得按普通下落小球模拟。状态8也是120tick，在80..16每8tick/每6tick发射（低/中难度），高难度85..16每5tick；x=Boss中心+rand127−64；vx=rand511/64−3/−4/−6，+1b0改128。证据40e2d7..40e53f。

### 状态3与6：追踪弹

状态3总88tick，在49/42/35/29/22发射角0xc000/0xa000/0xe000/0x9000/0xf000。状态6总88tick，在16时低难度发0xc000，中/高发0xe000及0xa000；高难度8时另发角0。分身独立回调41284f已核对并接入：各自停稳后计时，剩16tick时发0xe000与0xa000两弹，不与本体强制同步。

42447a→424714：每tick年龄+1，速度=min(age,40)/5，最大8px/tick。目标角差按最短有符号角处理。age<30转角差/128；30..59差/8；60..127若abs差≥16384则/128，否则/16；128..159差/64；160后不转；300tick移除。命中地形 `0x424e30..424e57` 使用402f11&0xF触发撞击。共享碰撞表499028的活动矩形 `(8,8,16,16)`。弹体effect1帧52/53各2tick循环（表499088）。

### 状态5：分身布局

40d762取折叠种子>>2模3决定本体在左/右/中哪个槽。三槽中心x=128/320/512；阶段1三个原生y80；阶段2左右槽y344，中间槽y192。全部初始在本体位置，x/y速度=目标差/16；本体差均<1px后等待30tick→state6。两分身各自独立接近、停稳、倒计时和发射，不共用本体的施法时钟。

### 状态9/10：瞬移横向攻击

9计时128；103时原生y移出场到496。127..104：scaleX=(timer−104)/20，scaleY=20/(timer−103)。25时重定位：玩家原生y≥288→Boss y344，否则192；玩家原生x≥320→x−160，否则x+160。25..1：scaleX=24/(26−timer)，scaleY=(26−timer)/24。0→state10。10总80tick，64时创建4252c6控制器，17tick后产生425805六个短横向对象，寿命6tick。控制器16tick时偏移改24,24，所以横向对象相对Boss原生左上角：左x−424，右x+56；三行y+16/+32/+48，攻击矩形宽448高16。左三行动画次序118/119/117、119/117/118、117/118/119；右三行117/118/119、118/119/117、119/117/118，每帧2tick。effect1，不应绘制为全屏随机激光。控制器本身effect1帧32..39、120..122，各2tick。证据425461..425805、425c93..425d08、4998a8和499a28。

### 状态11/12：加速弹连续射击

11总112tick，87离场，39时固定原生位置288,48；40..16恢复比例；0→12。12总120tick，HP<70为160、<50为180、<20为220。年龄达到40后每15tick（低难度）、达到35后每10tick（中）、达到25后每8tick（高）发425e8c。瞄准玩家方向加 `(rand4096−2048)*N/4`，N=4/6/8/12（HP100/70/50/20阈值）。出生点原生x+20,y+47。初速1.5px/tick，每tick增加0.2。

**关键：该弹不是追踪弹。** 426126虽然计算目标角差，但426670无条件将转向量清零，再更新角度。因此必须保留直线加速，不得因为存在类似追踪算法就擅自增加追踪。4268d7..4268fe地形碰撞同样&0xF。effect1帧52/53各2tick循环。

## 生命阶段与招式顺序

40ad36..40ad94：HP百分比<70进入phase1，<40进入phase2。普通难度≤64，phase0循环2,1,1,2,1,9；phase1循环2,1,1,2,9,5,2；phase2循环2,1,13,2,9,5,2。源码有混用%7和%6分支，这里按实际字面执行，没有“修正”成想象中的循环。难度≥128且折叠种子低字节<96、序号奇数时优先11；阶段1/2中低字节<96且序号&3==0时可优先5。主动作1/9/11冷却=(256−d)/6+90；2/5冷却=(256−d)/8+60。冷却在当前动作期间也在倒数。最终关配置普通基础难度32，网页默认64仅为宿主当前约定，不是声称原游戏所有模式都64。

## 三个 wiz_maru 帮手与电链

4094ce构造时调用409962三次，不是每次施法凭空产生一个球。相位0/0x5555/0xaaaa，槽标识0x30000/0x30001/0x30002，难度16/16/24，初始原生位置320,496；0,−16；640,−16，循环链接+0xe0。回调4102c3，贴图wiz_maru，裁切描述VA4954b0。

410f67..41117d按本体state在6/7/8/9/10/11/13切换帮手phase2/3，其他本体state切phase0/1。环绕目标半径64，中心本体(+40,+94−48)，相位取本体+1e4并按槽分三份；其他阶段按折叠种子选择场内位置，不固定追踪玩家。phase2→3生成24个409bfb子对象；phase0→1生成12个，均引用该帮手及其循环链接的下一个帮手。

模块已接入三帮手移动与子对象电链：帮手本体不直接碰撞伤人；链上16×16电点具有攻击判定，使用wiz_maru帧6..9。电点位置随两端变化，并按原分支加入小幅抖动。原生整数取整与完整受击回退仍未逐帧对齐。

## 当前实现可验证范围

`web/native-mage.js`是基于上述静态证据的独立模块，测试覆盖弹数、倒计时、分身独立施法、瞬移目的地、横向攻击、电链与不同帧率下固定tick一致性。原生帧率、整数截断、全局时间造成的漂浮偏差和受击打断尚不是逐帧等价。宿主按关卡参数32加初始化难度64传入96，并非所有敌人统一64。不能将静态规则测试通过宣传为整场Boss完全复刻；这些未证实项不应用自创技能补足。
